S3 3.1 Machines IBL

Use this sheet with your teacher. An online page cannot stand in for the practical: you still need the class, teacher-approved parts, a risk assessment and time to build and test. Related lessons: Force, Work and Simple Machines, Electric Current and Circuits, Magnetism and Electromagnetism, Project: Build a Simple Robot.

To print the brief and rubric, use your browser’s Print command (Ctrl+P or Cmd+P). Buttons are hidden in the print view. Rubrics stay on this page; there is no teacher grading database.

1 Brief and learning objectives IBL S3

Investigation: How does one chosen independent variable (for example motor on-time, or the number of turns on an electromagnet coil) affect a testable robot requirement (for example distance moved in centimetres, or paperclips held)?

The physical robot is a classroom product judged with a rubric. This page does not auto-grade the build and does not store a league of whose robot is best.

By the end of the practical you should be able to:

  • write a testable requirement and name independent, dependent and control variables;
  • use only teacher-approved parts and a followable method;
  • record repeats with units in the table headings;
  • say whether the requirement was met and what you would iterate.
2 Planning and variables
  • Independent: one quantity the teacher approves (for example on-time in seconds, or coil turns).
  • Dependent: the requirement measure (for example distance in cm, or number of paperclips).
  • Controls: same surface, same starting position, same battery if used, same way of starting the run.

Change one independent variable at a time. Draft the question in the lab book: “How does _____ affect _____ when _____ is kept the same?”

3 Safety and risk
  • Use only the kit the teacher supplies. No mains sockets. No home wiring tests for this sheet.
  • Moving parts can pinch. Hair and sleeves tied back if the teacher asks. Bags off the floor. No running.
  • Electromagnets and motors can get warm; follow the on-time the teacher sets.
  • Do not harvest private home-workshop photos into the app. Evidence stays in the lab book.
  • Your teacher’s risk assessment is the one that counts.
4 Data table and graph

Put units in the headings. Keep every raw value, then calculate the mean if you repeat the run. Do not delete an inconvenient value without saying so in the evaluation.

A simple graph: independent variable on the horizontal axis, mean dependent value on the vertical axis. Label both axes with quantity and unit.

5 Analysis and evaluation

Did the mean meet the written requirement? Quote numbers from the table. If a run missed, that is evidence for iteration, not a stored ranking.

Evaluation prompts:

  • Was the independent variable the only thing that changed?
  • Would more repeats reduce random scatter?
  • What would you change so another group could trust the evidence?
  • How is a class rubric different from a popularity league in an app?
