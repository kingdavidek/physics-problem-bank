1 Force as a vector 3.1.1 S3

A force is a push or pull between objects. Opening a classroom door, sliding a crate across the floor, or lowering a box on a pulley are all force stories. In this S3 model a force is drawn as a vector: it has size and direction. A force is a push or pull. A vector has size and direction. Forces are interactions, not a ranking of classmates.

Size is how strong the push or pull is. The unit used here is the newton (N). Direction is which way the force points: right, up, or along a ramp. On a sketch, a longer arrow means a larger force; the arrow heading is the direction.

Worked example: A trolley in the corridor is pulled to the right with 8 N. That force is not “8” on its own: it is 8 N to the right. A 4 N pull the same way is a shorter arrow. A 4 N lift is the same size but a different direction, so it is a different vector.

Forces are interactions. This page never ranks how strong classmates are, and it does not store a map of anyone’s joints.

2 Simple machines

A simple machine can change the size or direction of a force so a job is easier to set up. It does not create energy. This lesson names three types used in S3: a lever, a pulley and a ramp. A device that can change the size or direction of a force. It trades force and distance; it does not create energy.

Public examples, not a kit you have to own:

  • Lever: a door handle, a bottle opener, or a playground see-saw. A long handle can turn a smaller push into a useful turn about a pivot.
  • Pulley: a flagpole rope or a classroom blind. The wheel can change the direction of the pull so you haul down to lift up.
  • Ramp: a loading slope into a van, or a wheelchair access ramp. A longer path can mean a smaller effort force.

3 Lever parts

A lever is a bar that turns about a pivot. Label three parts every time:

  • A effort — the input force you apply.
  • B fulcrum — the pivot the bar turns about.
  • C load — what is being moved.
Effort is the input force, the fulcrum is the pivot, and the load is what is moved. Labels, not a private joint map.

Where those parts sit changes the story. On a door, the hinge is the fulcrum. A push far from the hinge (a long effort arm) opens the door with a smaller force than a push next to the hinge. A wheelbarrow puts the load between the wheel (fulcrum) and the handles (effort), so a smaller lift at the handles can raise a heavier load.

Worked example: In a classroom model, a metre stick rests on a triangular block. A 2 N push at A, 40 cm from the fulcrum, balances a load at C. The sketch is a labelled bar, not a realistic machine and not a map of anyone’s joints.

4 Force–distance trade-off

A simple machine can trade a smaller force for a larger distance (or the reverse). You do not get something for nothing: if the effort force is smaller, that effort usually has to move further.

A ramp is the public example. Lifting a crate straight up is a short path, but the force is large. Pushing the same crate up a long slope uses a smaller force over a longer path. A single pulley that only changes direction does not shrink the force; a longer ramp, or a lever with a longer effort arm, does.

Worked example: A loading ramp into a van is 4 m long and 1 m high. The crate still has to gain that 1 m of height, but the push can act along 4 m. The class compares “short lift, large force” with “long ramp, smaller force”. Nobody is asked for power in watts.

5 Work as W = Fd

Work in this lesson is force times distance along the same line. The unit is the joule (J). If the force and the motion are not along the same line, this S3 formula does not apply as written. Work is force times distance along the same line. The unit is the joule. Power (work per time) is not claimed in this module.

Holding a bag still is tiring, but in this model the distance along the force is zero, so \(W = 0\). Sliding the same bag 3 m across a table with a steady 5 N pull along the table does count as work.

Worked example: \(W = Fd\). A classroom pull of 5 N along 3 m on the same line is \(W = 5 \times 3 = 15\) J. Check the units: newton times metre is a joule. Nobody is asked for power in watts, and the time taken is not used.

6 Body levers

Bones and joints can be modelled as levers. Use a fictional case only. This page does not store a map of a pupil’s joints, and it does not ask anyone to measure their own arm.

A common classroom model is a forearm raising a bag. The elbow is the fulcrum. The bag at the hand is the load. The muscle effort acts closer to the elbow than the bag, so the effort force is larger than the load. That is the force–distance trade-off the other way: a large force over a small muscle distance can still move the load through a larger arc.

Worked example: In a labelled sketch, a 4 N bag is the load at C. The elbow is fulcrum B. The effort A is the muscle pull closer to the fulcrum. The class labels effort, fulcrum and load. That is a teaching model, not a medical file and not a named pupil’s arm.

7 Limits: no power claim

Power (work per time) is not claimed in this S3 module. Keep work as \(W = Fd\) in joules. A faster lift and a slower lift of the same crate through the same distance can have the same work in this model; this lesson does not ask which was more powerful.

A machine still does not create energy. It trades force and distance. The next lesson (Energy) takes up forms, transfers and conservation. The robot project later in 3.1 can use a lever, a pulley or a ramp from this page — still without a power calculation.

If a question mentions watts, \(P = W/t\), or “how fast the work is done”, it is outside this syllabus cell. Stay with newtons, metres and joules along the same line.

8 Using this lesson

Keep the ideas separate, then chain them on a labelled sketch:

  1. Draw each force as a vector (size and direction).
  2. Name the machine type (lever, pulley or ramp).
  3. On a lever, label effort, fulcrum and load.
  4. State the force–distance trade-off in words.
  5. If force and distance are along the same line, calculate \(W = Fd\) in joules.
  6. Do not calculate power, and do not turn a body example into a private joint map.

Energy continues next. A later robot build can choose a machine that matches the job; this lesson only supplies the force and work language.
