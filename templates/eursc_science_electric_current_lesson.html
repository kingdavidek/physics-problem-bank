1 A complete loop 3.1.4 S3

A complete circuit is a loop that allows current. Opening a switch can break the loop. A cell, B lamp, C switch — schematic boxes, not a home inspection. A circuit is a closed loop that allows current. Current is a flow of charge around that loop. A gap at the switch stops the loop.

Worked example: In a classroom kit, the cell, lamp and switch sit on one loop. When the switch is closed, the lamp can light. When the switch opens, the loop is broken and the lamp goes out. Nobody inspects a mains socket for this quiz.

2 Series

A series circuit has one path. If that path opens, the loop stops. One path for current. The cell, lamp and switch in the figure share that single path.

Worked example: Two lamps in series share one loop. If either lamp is removed, the path opens and both go out.

3 Parallel

A parallel circuit has more than one path. A second lamp on its own branch is a teaching example. More than one path for current. One branch can open without stopping every other branch.

Worked example: Two lamps in parallel each have their own loop back to the cell. If one lamp is removed, the other branch can still be a complete loop, so that lamp can stay on. This is a path idea only; this lesson does not calculate \(V = IR\).

4 Conventional current and electrons

Conventional current is a direction convention. Electron flow is distinguished from that arrow in this teaching model. Both describe the same loop. Conventional current is the arrow direction used on many diagrams. Electron flow is the opposite direction in a metal. Both name the same closed loop.

7 Meters, qualitative only

Meters are read qualitatively here: a needle that moves, or a reading that is larger or smaller. This S3 claim does not include \(V = IR\) or resistance calculations.

Worked example: With the switch closed, a classroom ammeter needle moves. With the switch open, it stays at rest. The class names “current on” or “current off”. Nobody is asked to calculate a resistance.
