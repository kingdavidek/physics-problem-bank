2 Elements and atoms

An element is a substance made of only one type of atom. A jumble of different particles is a mixture, not a single element. One type of atom throughout. Iron is an element; salt water is a mixture. An atom is a single particle of an element.

A chemical symbol is a short name for an element, not a weather sentence. For example: H hydrogen, O oxygen, C carbon, Fe iron. The letters are labels for atom types.

5 Reactions as rearrangement

A chemical reaction rearranges atoms. It does not create a new type of element from nothing and it does not destroy all atoms so that none remain. Burning hydrogen in oxygen to make water is hydrogen and oxygen atoms changing partners.

6 Word equations

A word equation names reactants and products. Examples: hydrogen + oxygen → water. Carbon + oxygen → carbon dioxide. The arrow means “react to form”. It is a sentence about substances, not a spell that invents a new atom type.

Worked example: hydrogen + oxygen → water. Count the idea: hydrogen and oxygen atoms are still there, now joined as water molecules. The equation does not create iron.
